# Retours

Les retours d'Ethan s'accumulent ici, au fil des tests sur le téléphone :
Ethan dicte, Claude range. **Un lot RETOURS les traite tous ensemble.** Seul un
bloquant (le jeu plante, la sauvegarde est perdue) passe devant, dans un lot
court.

Chaque entrée suit le même format :

```
- [date] écran : … · ce qui se passe : … · ce que j'attendais : …
```

et acceptés par Ethan le 02/10. Ils attendent le lot RETOURS-C1.
